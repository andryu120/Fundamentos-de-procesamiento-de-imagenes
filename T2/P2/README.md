# Pregunta 1: Difusión Anisotrópica y Variación Total

Este directorio contiene la implementación de la Pregunta 1

## Estructura de Archivos
* **`creacion_imagen.py`:** Contiene el código para cargar la imagen original y aplicarle ruido Gaussiano.
* **`procesamiento.py`:** Contiene las funciones de Difusión Anisotrópica, junto con las funciones para calcular los coeficientes de difusión de Variación Total (TV), Laplaciano Exponencial y Laplaciano Racional Modificado.
* **`main.py`:** Este archivo se encarga de la ejecución principal del programa y donde se generan las imagenes a analizar.

## Instrucciones de Ejecución y Reproducción de Resultados


Para generar las imágenes modificadas que se analizan en el informe, ejecute:
```bash
python main.py
```
Los resultados se mostraran en pantalla
