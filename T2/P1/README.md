# Pregunta 1: Ruido Poisson y filtrado Gaussiano adaptativo

Este directorio contiene la implementación de la Pregunta 1

## Estructura de Archivos
* **`creacion_imagen.py`:** Contiene la generación de la imagen sintética y la función que aplica ruido Poisson.
* **`procesamiento.py`:** Acá se encuentran las funciones de filtrado, , el RMSE, y del filtro espacialmente adaptativo .
* **`main.py`:** Este archivo se encarga de la ejecución principal del programa. En este archivo se generan las figuras y gráficos de RMSE.

## Instrucciones de Ejecución y Reproducción de Resultados


Para generar las imágenes modificadas que se analizan en el informe, ejecute:
```bash
python main.py
```
Los resultados se mostraran en pantalla
