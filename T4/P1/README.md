# Pregunta 1: Pirámide Laplaciana y transformada starlet

Este directorio contiene la implementación de la Pregunta 1

## Estructura de Archivos
* **`procesamiento.py`:** Funciones para cargar la imagen y calculo de RMSE
* **`main.py`:** Este archivo se encarga de la ejecución principal del programa y donde se generan las imagenes a analizar.
* **`Laplace.py`:** Implementacion de la Piramide Laplaciana junto con su reconstruccion
* **`Starlet.py`:** Implementacion de la Transformada de Starlet junto con su reconstruccion
* **`graficar.py`:** Funciones para visualizar los resultados.

## Instrucciones de Ejecución y Reproducción de Resultados


Para generar las imágenes modificadas que se analizan en el informe, ejecute:
```bash
python main.py
```
Los resultados se mostraran en pantalla
