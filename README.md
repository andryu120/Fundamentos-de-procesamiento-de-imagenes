# Tareas - IEE2714 Fundamentos de Procesamiento de Imágenes 

Este repositorio contiene las tareas del curso IEE2714. 

## Estructura del Repositorio
* `Tarea_1/`: Contiene el código fuente, imágenes de prueba y el README específico para la Tarea 1 (En cada pregunta).
    * `Pregunta_1/`: Implementación de Saturación Selectiva de Color.
    * `Pregunta_2/`: Implementación de Ecualización Local.
    * `Pregunta_3/`: Implementación de Reescalado e Interpolación.

## Requisitos Previos
Para ejecutar los scripts de este repositorio, se requiere un entorno con Python 3.x y las siguientes librerías:
* `numpy`
* `opencv-python` (cv2)
* `matplotlib` (opcional, para generación de gráficos adicionales)

Para instalar las dependencias, ejecute:
`pip install numpy opencv-python matplotlib`
