# Pregunta 3: Reescalado e interpolación bilineal

Este directorio contiene la implementación  correspondiente a la Pregunta 3.

## Estructura de Archivos
* **`procesamiento.py`:** Aquí se encuentran las funciones encargadas de realizar interpolaciones, ademas de cargar y guardar imagenes `imagenes`.
* **`main.py`:** Este archivo se encarga de la ejecución, aca se realizan todas las pruebas de parametros que estan en el informe.

## Instrucciones de Ejecución y Reproducción de Resultados

Para ejecutar el procesamiento, corra el siguiente archivo desde la terminal:

```bash
python main.py

```
Los resultados se guardarán automáticamente en el directorio `imagenes`
