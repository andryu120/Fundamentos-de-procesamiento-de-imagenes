# Pregunta 2: Ecualización local y control de contraste

Este directorio contiene la implementación  correspondiente a la Pregunta 2.

## Estructura de Archivos
* **`procesamiento.py`:** Contiene las funciones que generan las regiones y aplican las transformaciones.
* **`main.py`:** Archivo de ejecución del programa que cuenta con funciones para la prueba de parámetros.

## Instrucciones de Ejecución y Reproducción de Resultados

Para reproducir  resultados mostrados en el informe, ejecute el siguiente comando en la terminal:
```bash
python main.py
```
