# Pregunta 1: Saturación Selectiva de Color

Este directorio contiene la implementación de `ColorSaturation`, capaz de modificar la saturación de una imagen RGB en función de su tono.

## Cómo ejecutar el código
Para hacer cambios en las imagenes, ejecute el script principal desde la terminal:

```bash
python main.py

```
## Ver las imagenes modificadas
Luego de ejecutar el codigo vaya a las carpetas "imagenes_modificadas", dentro de ellas van estar las dos imagenes con tu titulo correspondiente
